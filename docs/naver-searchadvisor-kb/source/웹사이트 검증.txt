제목 : 사이트 간단 체크
url : https://searchadvisor.naver.com/guide/diagnose-site
내용 : 
서치 어드바이저에서 제공하는 사이트 간단체크는 웹마스터도구에 사이트를 등록하기 이전에 사이트의 검색 최적화 여부(SEO)를 체크할 수 있는 진단도구입니다. 사이트를 직접 개발하기 어려운 상황이라면 SEO를 준수하는 템플릿을 제공하는 좋은 업체를 이용하는 것도 한 방법입니다. 사이트 구축이전에 업체의 포트폴리오를 받아서 간단체크를 실행해 보세요. 검색 최적화를 잘 준수하고 있는지를 실시간으로 확인해 볼 수 있습니다.

사이트 간단체크

사이트 간단체크를 실행하면 실시간으로 해당 사이트의 메인 페이지를 방문하여 HTML 분석 후 결과를 보여줍니다. 간단체크 결과 리포트를 참고하여 사이트 개발 담당자와 함께 점검해보세요.

검색로봇
네이버 검색로봇이 사이트에 정상적으로 접근이 가능한가요?
네이버 검색로봇이 사이트의 정보를 수집할 수 있나요? (robots.txt)
사이트 제목, 사이트 설명이 설정되어 있나요? (title, description 메타 태그)
네이버 검색이 보유하신 사이트를 검색에 반영할 수 있나요? (noindex 설정 없음)
사이트 제목, 사이트 설명이 너무 길지는 않은가요? (제목은 40자, 설명은 80자 이내로 작성하기를 권장합니다.)
사이트 제목, 사이트 설명에 반복되는 단어가 많이 있지는 않나요?
혹시 사이트 콘텐츠와 관련이 없는 키워드가 들어가 있지 않나요?
생성되는 콘텐츠를 검색에 누락 없이 반영하기 위해 웹마스터도구를 통해 rss, sitemap을 제출하였나요?
콘텐츠
사이트가 꾸준히 관리되고 있나요?
게시판 등에 스팸 게시글이 생성되지는 않았나요?
사이트 내에서 주제와 관련된 나만의 콘텐츠가 게시되고 있나요?

제목 : URL 검사
url : https://searchadvisor.naver.com/guide/url-inspection
내용 : 
웹마스터도구에서 제공하는 URL 검사는 네이버 검색로봇이 사이트의 콘텐츠 수집과 색인 정보를 제공하는 도구입니다.
추가로 URL 문서의 메타와 SEO 정보를 제공하여 최적화가 부족한 부분을 안내하고 있습니다
색인/Meta/SEO 각 항목은 세 테이블로 분리되어 노출되고, 클릭시 상세 내용이 하단에 노출됩니다.
(각 항목의 데이터가 있는 경우만 테이블이 노출됩니다.)
image

색인
URL 상태(StatusCode)와 수집 여부, 색인 가능 여부, 색인 여부를 제공합니다.
색인 테이블을 통해 내 URL이 수집되었는지, 수집되었다면 검색에 노출될 수 있는지(색인 여부)를 확인해 볼 수 있습니다.
우측 아이콘은 문서 상태(색인, 수집, 미수집) 여부를 색상으로 표시합니다.
image

Meta
HTML에 삽입된 메타 정보를 제공합니다. 결과를 보고 문제가 있다면 수정해주세요.
우측 아이콘은 제목, 설명문 추출 가능 여부를 표시합니다.
image

SEO
검색엔진 최적화가 필요한 요소를 확인하여 제공합니다.
수집과 색인에 영향을 미치는 요소들이 무엇인지 확인하고 수정해주세요.
우측 아이콘과 SEO 요소별 색상은 SEO 중요도(반드시 수정, 수정하면 좋음, 유지해도 좋음)를 색상으로 표시합니다.
