제목 : 검색노출 제목 및 설명문 갱신
url : https://searchadvisor.naver.com/guide/faq-serpedit
내용 : 
Q. 네이버 웹 검색에서 노출되고 있는 정보가 잘못되었어요
웹 검색에 노출되는 정보는 검색 로봇에 의해 자동으로 수집 및 분석된 정보이므로 네이버에서 임의로 수정할 수 없습니다.

따라서 사이트 운영자가 직접 정보를 수정해야 변경된 내용이 반영될 수 있습니다.
만일 해당 사이트의 운영자라면, 아래 도움말을 참고하여 직접 수정해 주시기 바랍니다.

▶ 페이지 제목 및 설명 마크업 가이드 바로가기

특히 로봇 수집이 전부 또는 일부 불가하거나 원활하지 않은 경우, 정보의 갱신이나 분석이 원활하지 않을 수 있습니다. 원활한 수집이 될 수 있도록 확인도 부탁드립니다.

URL에 대해
검색 엔진은 수집해온 문서들을 시시각각 분석하여, 동일한 내용을 가지고 있거나, 같은 페이지로 리다이렉트되는 문서 등을 정리해 대표 페이지를 추출, 검색 결과로 제공합니다. 이 경우 사이트 운영자님이 설정하지 않은 URL이 선정될 수 있으며, 이에 대한 네이버의 임의 수정은 불가능합니다.

다만, 선호 URL을 지정하는 등으로 운영자님이 대표로 하고 싶은 URL을 참고 정보로 검색 엔진에 알려줄 수 있으며, 불필요한 리다이렉트나 중복된 문서를 운영하는 서버에서 삭제하는 것도 URL 개선에 도움이 될 수 있습니다.

제목과 사이트 이름, 설명문에 대해
검색 엔진은 기본적으로 해당 문서가 보유하고 있는 제목 태그 정보와 페이지 내에 제목으로 볼 수 있는 요소들을 분석하여 이용하고 있습니다.

다만, 정책상 검색 품질 향상 및 결과를 더욱 효과적으로 노출 시키기위해, 똑같은 제목이나 설명문을 가진 페이지가 다수 발견되거나, 구체적이고 간결하지 못하다고 엔진이 판단될 수 있는 경우, 로봇 수집에 지장이 있거나 불완전한 경우 등에, 앵커 (다른 페이지에서의 언급 등) 정보나 페이지에 있는 다른 텍스트 등을 활용하여 제공하는 경우가 있습니다.

가능하시면 콘텐츠 마크업 가이드라인에 제목과 설명문 작성 tip 을 참고해서 설정해주시면 도움이 됩니다.

이미지에 대해
검색 결과에 대한 만족도 향상을 위해 검색 엔진은 문서 내용 등을 분석해 고유성이 있는 썸네일 이미지도 함께 표시하는 것이 적합하다고 판단하는 경우, 자동적으로 이를 노출하는 경우가 있습니다.

다만, 표시되는 이미지는 엔진이 자동으로 분석한 결과이므로, 인위적 노출은 어려우며, 웹 마스터님이 선호하는 것이 노출되지 않을 수도 있습니다. 특히 이미지도 웹 문서와 별도로 로봇에 의해 수집되어야 분석/노출 가능하기에, 내용 수정시 웹 문서와 별도로 반영에 시간이 걸리는 경우가 있습니다.

추가로, 분석에 본문 등 외에 오픈그래프 이미지 태그도 대상으로 이용되는 경우가 있으며, 콘텐츠 마크업 가이드 의 관련 항목을 참고할 수 있습니다.

Q. OG (Open Graph) title, description 태그와 기본 title, description 태그의 다른점은 있나요? 네이버 웹 검색에서는 이 두가지 태그를 어떻게 활용하고있나요?
HTML 문서내에서 참고하는 태그가 다릅니다.
둘다 사이트명/설명문을 뜻하며 웹페이지가 검색결과에 노출하는 제목, 설명문이 됩니다.

1. 사이트 제목
사이트명 : HTML 문서의 태그내에 있는 <title>페이지 제목</title> 태그 입니다.
Open Graph 제목 : HTML 문서의 태그내에 있는 <meta property="og:title" content="페이지 제목"> 메타 정보 입니다.
2. 사이트 설명
사이트설명 : HTML 문서의 태그내에 있는 <meta name="description" content="페이지 설명"> 메타 정보 입니다.
Open Graph 설명 : HTML 문서의 태그내에 있는 <meta property="og:description" content="페이지 설명"> 메타 정보 입니다.
네이버 웹 검색에서는 사이트 제목, 설명이 Open Graph 제목, Open Graph 설명과 다른 경우, 색인 과정에서 검색에 최적화된 값을 선택하여 검색 결과에 반영됩니다.

먼저 내 사이트가 네이버에 색인이 되었는지 확인합니다
네이버 검색창에 site:사이트 URL 로 검색을 합니다.

예)
site:https://www.example.com

site검색

site: 검색을 했을때 사이트가 보인다면?
네이버에서 귀하의 사이트를 인식하고 페이지를 수집하여 색인을 진행했다라는 뜻입니다.

site: 검색을 했을때 사이트가 보이지 않는다면?
네이버 검색 로봇이 아직 해당 문서를 수집하지 못했거나, 눈에 보이는 것과 달리 여러가지 이유로 수집/색인이 불가능한 문서일 가능성이 있습니다.

방대한 인터넷 상의 웹 문서 수에 비해, 제한된 수의 로봇으로 수집하는 특성상, 수집이나 정보 갱신이 충분하지 못한 경우가 있을 수 있으며,
특히, 생성한지 얼마 안된 사이트의 경우 네이버에서 사이트의 존재 여부를 아직 알지 못하는 경우가 있습니다.
가능하시면 웹마스터도구 사이트 등록과 소유 확인을 통해 사이트가 존재함을 알려주시면, 반영에 도움이 될 수 있습니다.

또한, 웹사이트가 방화벽 제어를 하거나 검색 엔진에의 노출을 비허용하거나 페이지 필수 구성요소의 수집이 어려운 등 수집/반영이 어려운 환경에 있을수 있습니다.
서치어드바이저에 사이트 간단체크를 통해 사이트와 관련된 정보를 조회하시면 도움이 되실 수 있습니다.

Q. 내사이트가 네이버에 노출이 되지 않습니다. 왜 그런건가요?
귀하의 사이트가 검색결과에 없을경우, 여러가지 원인으로 노출이 되지 않을수 있습니다.
아래의 사유에 해당하는지 확인해보세요.

robots.txt 내에서 수집 비허용 또는 문서 내에 noindex 메타태그, 웹 서버에서 로봇 수집 비허용 HTTP 헤더 (X-Robots-Tag)가 설정되어 있을 수 있습니다.
특히 핵심 문서 외에 주요 리소스 파일이 수집 불가능한 경우에도 노출에 지장이 있을 수 있습니다.
네이버의 검색로봇이 사이트의 방화벽을 통과하여 접속할 수 없도록 서버에 제한이 설정되어 있을 수 있습니다. 검색로봇 확인 가이드
사이트가 웹 표준에 맞지 않게 개발되어 있을 수 있습니다. 특히 대표 URL 설정등과 같은 웹표준 최적화 작업을 진행 하는것을 권장 드립니다.
중복된 문서가 다른 주소로 반영되어 있을 가능성이 있습니다. 다른 URL 또는 통합검색의 다른 검색 DB에 사이트나 문서가 게제되어 있는지도 확인해 주십시오.
검색에 노출하기에는 콘텐츠 품질이 적합하지 않을 수 있습니다. 성인물, 불법정보를 다루고 계시지 않으신가요? 혹은 사이트 내 게시판 관리가 안되어 스팸 문서들로 도배되어 있지는 않으신가요? 웹 콘텐츠 스팸사례 를 참고하여 스팸으로 분류될수 있는 사례들을 확인해보세요.

제목 : 웹 검색 제외
url : https://searchadvisor.naver.com/guide/faq-serpremove
내용 : 
네이버 검색의 사이트 제외 방침
네이버는 법률 위반, 저작권 위반과 같은 정책위반의 경우에만 네이버 검색 결과에서 삭제 할수 있습니다. 사이트가 정상적으로 접속되고 있다면 네이버에서 임의로 삭제할 수 없는 점 양해 부탁드립니다.

웹페이지의 차단 또는 삭제는 대개 웹사이트를 제어하는 관리자 또는 소유자를 통해 조치가 되어야 합니다. 콘텐츠를 삭제할 권한이 있는 오너에게 삭제요청을 해야하는 이유는 검색결과에서 삭제되더라도 콘텐츠 자체가 삭제된것이 아니기 때문에 관련 페이지는 여전히 남아 사이트 링크 URL, 소셜미디어와 다른 검색엔진등에 표시될 가능성이 높기 때문입니다.

법적 근거가 될수 있는 명예훼손 등에 의해 게시물 삭제에 대한 법원 명령을 가지고 있는 경우 고객센터에 문의해주세요.

Q. 제가 소유하는 사이트를 네이버 검색결과에 제외하고 싶습니다.
사이트를 폐쇄하는 것이 아닌, 네이버 검색에서만 제외 싶으시다면 아래와 같은 작업중 하나 또는 이상을 진행해야합니다.

1. 웹페이지 내 NOINDEX 메타태그를 삽입합니다
<head><meta name="robots" content="noindex"></head>

모든 문서에 명시해야하는 번거로움이 있지만 위 메타태그를 추가하면
로봇은 해당 문서는 검색 결과에 노출을 원하지 않는다는 것을 알 수 있게 됩니다.

단, 단순히 다른 URL로 리다이렉트 되는 페이지인 경우에는, 이 설정만으로 URL이 제외되지 않을 수도 있습니다.
이 경우에는 robots.txt도 추가 설정하거나, 리다이렉트 타겟이 된 페이지들에도 noindex 메타 설정이나 완전 삭제 처리가 필요합니다.

2. 웹페이지를 완전 삭제 또는 에러 페이지 반환
웹페이지가 더이상 필요가 없다고 생각될 경우, 웹서버에서 403 (Forbidden) 또는 404 (Not Found)과 같이 알맞은HTTP 응답 코드를 반환하도록 조치합니다.
유사하게 에러 페이지로 리다이렉트 시키거나, 인증이 필요한 페이지임을 안내하는 방법도 가능합니다. 다만, 페이지 구성에 따라 정상적인 응답으로 로봇이 오인하는 경우도 있기 때문에 주의가 필요합니다.

특히 내용물을 그대로 둔 상태에서, javascript나 CSS를 이용하여 화면을 덮는 형태 등으로 에러 메시지나 로그인 등을 불러오게 하는 등의 기법을 사용하는 경우에는
로봇의 페이지 해석 과정에서 이 정보가 제대로 인식되지 않을 수 있습니다.

주의: robots.txt를 먼저 설정하거나 서버의 네트워크를 먼저 정지하거나 블럭하지 마세요
robots.txt는 검색 로봇의 추가적인 접근을 차단하는 설정으로써, 해당 문서나 사이트가 인터넷 상에서 사라졌는지와는 무관합니다.

즉, 해당 사이트나 문서가 삭제되었는지를 확인하기 위해서는 로봇이 그 사이트를 방문해서 확인해야 합니다만.
robots.txt 등이 앞에 설정되면, 이를 확인하기 위한 접근 조차도 차단되기 때문에, 원하시는 동작이 되지 않을 수 있습니다.

또한, 서버의 네트워크를 무조건 정지하거나 네트워크 레벨에서 블럭하면, 위와 마찬가지로, 로봇 입장에서는 이 서버가 계속 운영중이나 일시적 오류인지 등을 파악할 수 없으므로,
원하는 바의 반영이 불가능할 수 있습니다.

만일 향후에도 검색 노출을 원하지 않는 경우에는, 먼저 가이드에 따라서 삭제를 진행하시고, 관련 페이지가 모두 검색에서 사라진 것을 확인하신 다음 robots.txt 등을 설정하실 것을 추천드립니다.

Q. 제가 소유하고 있는 사이트의 특정 페이지만 검색결과에 제외하고 싶습니다.
특정 페이지만 검색결과에 제외 시키고 싶을경우, 제외 시키고자 하는 페이지의 <head> 태그안에 아래와 같은 태그를 삽입합니다.

<head><meta name="robots" content="noindex"></head>

네이버 검색 로봇이 페이지 재방문시 해당 태그를 인식하여 색인에서 제외 합니다.
조금 더 빠른 검색 로봇 방문을 원하신다면 웹마스터도구를 활용하여 수집요청이 가능합니다.

Q. 접속할수 없는 페이지를 네이버 검색결과에 제외하고 싶습니다.
페이지가 삭제가 되었다면, 삭제된 내용이 검색결과에 반영되기 까지 조금만 기다려 주세요. 일정 시간이 지나면 업데이트 과정을 거쳐 자동으로 검색결과에서 제외됩니다.

웹마스터도구 소유확인을 마친 사이트라면, 웹마스터도구를 활용하여 페이지 제외요청이 가능합니다. 웹마스터도구 로그인 후, 요청 > 웹페이지 검색 제외 메뉴를 통해 하위 주소를 입력하고 확인 버튼을 누릅니다.

단, 원본을 삭제하지 않거나, 검색 수집 제한을 하지않은 페이지는 검색결과에 다시 노출될수 있으니 유의해 주세요!

Q. 웹사이트 운영자가 연락이 되지 않습니다. 더이상 운영하지 않는 사이트는 어떻게 네이버 검색결과에 제외시키나요?
웹사이트 운영자 (웹마스터)가 협조가 어려운 경우 사이트 호스팅 업체 등에 문의 해볼 수 있습니다.
대부분의 사이트 호스팅 업체는 https://후이즈검색.한국/ 과 같이 whois 정보를 찾을수 있는곳에서 사이트 URL를 검색하면, 호스팅업체의 연락처와 같은 정보를 알아낼수 있습니다.

Q. 서브링크란 무엇인가요?
서브링크는 웹사이트의 구조를 자동으로 분석하여, 사용자가 원하는 정보를 쉽게 탐색 할수 있도록
네이버 검색 결과 중 일부 설명문 위에 링크들로 표시 되는 부분을 말합니다.

image

Q. 서브링크 노출 방법이 알고싶습니다
서브링크는 검색 엔진에 의해, 검색에서 판단하는 유용한 웹 문서를 대상으로 사용자의 선호 및 구조적으로 중요하다고 판단되는 링크를 자동으로 분석해 노출하고 있습니다.

따라서 별도의 요청에 의해 추가가 되지 않으며 링크 내용은 시시각각 변화할 수 있습니다.

검색 엔진이 좋은 서브링크를 추출할수 있도록 하기 위해서는 웹사이트 구조를 분석하기 좋은 바탕을 만들어야합니다.
아래와 같은 사항을 점검해주시면 도움이 될 수 있습니다.

1. 웹 표준을 준수 해주세요
javascript 로 된 link 사용을 피해주세요.
fragment (#) URL은 사용하지 마세요 (자세한 사항은 자바스크립트 검색 최적화 가이드라인 참고)
HTML 링크의 앵커 텍스트를 꼭 넣어주세요. 좋은 앵커텍스트는 검색엔진에게 링크에 대한 맥락을 알려줍니다.
<a href="http://www.example.com">앵커텍스트</a>
HTML 이미지를 사용하실 때에도 이미지에 대한 설명문인 alternative text (alt) 를 꼭 넣어주세요.
<img src="example.gif" alt="이미지에대한설명">
텍스트로 쓸 내용을 이미지로 만드는 것은 권장하지 않습니다.
그외 웹마스터 가이드라인을 참고해주세요.
2. 구조화된 내비게이션 구성과 사이트맵을 제공 해주세요.
GNB (Global Navigation Bar) 는 웹사이트의 얼굴이라 할수 있습니다. GNB 를 통해 내 웹사이트가 어떤 페이지 또는 기능을 제공하는지 사용자가 쉽게 알수 있게 해주세요.
[navercorp.com 의 GNB 예]
naverGNB

Q. 최근 사이트 구조를 변경했습니다. 언제 서브링크가 업데이트 될까요?
검색로봇이 사이트 정보를 재수집해야 서브링크가 업데이트 될 수 있습니다.
다만 재수집하여 반영하는데 일정 시간 (평균 7일 이내)이 소요되는 점 참고해주세요.

사이트 개편이 있었다면 혹시 검색 로봇의 접근이 원활한지 부분적으로 차단되고 있는 것이 없는지도 아울러 살펴봐주시기 바랍니다.

Q. 잘못된 정보의 서브링크가 노출되고 있습니다. 삭제는 어떻게 하나요?
서브링크 노출을 원하지 않는 경우에는 <a>태그에 rel="nosublink" 속성 값을 추가해 주세요.

<a href="https://www.mysite.com/attend" rel="nosublink">출석체크</a>
만약, 네이버 검색결과에 여러분 사이트의 모든 서브링크를 노출에서 제외하고 싶다면 html의 head 영역에 아래와 같이 meta 태그를 추가해 주세요,

<head>
<meta name="naver" content="nosublinks">
</head>
잘못된 서브링크 또는 개인정보등이 노출되고 있어 삭제가 필요한 경우, 아래 링크를 통해 삭제 요청이 가능합니다.

잘못된 서브링크 삭제 요청하러가기

다만, 링크의 부분 삭제가 불가능할 수 있으며 요청의 처리에는 시간이 걸릴 수 있습니다.
신고에 의해 서브링크가 삭제되면 영구적으로 제외되어 복구가 불가할 수 있으니 되도록 위의 설정 방법을 통해 직접 설정해 주세요.

제목 : 사이트 등록 및 소유확인
url : https://searchadvisor.naver.com/guide/faq-start-register
내용 : 
네이버 웹 검색은 웹 수집 로봇이 자동으로 수집한 사이트 정보를 반영하여 노출하고 있습니다. 따라서 검색 등록 절차는 존재하지 않습니다. 검색엔진 최적화 가이드를 참고하여 검색로봇이 웹사이트를 잘 수집할 수 있도록 조처를 하는 것이 우선입니다.

네이버 웹마스터도구에 사이트를 등록하지 않아도 네이버 검색 결과에 사이트 및 웹문서들이 반영됩니다. 하지만, 네이버 웹마스터도구에 사이트 등록후 소유확인절차를 진행하면, 사이트내 콘텐츠의 수집, 색인, 노출정보를 리포트를 통해서 파악 할 수 있습니다. 소유확인 이후에는 웹마스터도구의 리포트를 활용하여 내 사이트의 검색 연동 상황을 확인할 수 있으므로 사이트 운영에도 많은 도움이 될 수 있습니다.

소유확인은 자바스크립트 실행을 지원하지 않으니 마크업 확인은 최신 웹브라우저의 URL 입력란에 view-source:사이트_URL 을 입력하거나 페이지 소스보기를 활용하시기 바랍니다.

서치어드바이저에서 소유 확인용 메타태그 및 HTML 검증 시 주의해야 할 점은 아래와 같습니다.

서치어드바이저에서 소유확인용 메타태그 검증 시 자바스크립트, meta refresh, cookie 를 활용한 브라우저단의 리다이렉션은 지원하지 않습니다. 리다이렉트가 필요하다면 웹서버에서 처리되는 http 리다이렉트 (301, 302)로 처리해주세요.
# another.html 에 존재하는 소유확인용 메타태그 확인 불가
<head>
...
<meta http-equiv="refresh" content="0;url=another.html">
...
</head>
# another.html 에 존재하는 소유확인용 메타태그 확인 불가
<html>
...
<script lang=javascript>
window.location.href = "./another.html"
</script>
...
</html>
# 소유확인용 메타태그 확인 불가
<html>
...
<script lang=javascript>
document.cookie = 'sample_key=sample_value'
window.location.reload();
</script>
...
</html>
소유확인용 메타태그 정보가 html frame 태그 내에 존재 시 검증에서 제외 처리합니다. frame 태그가 아닌 html head 태그 내에 기입해 주세요.
...
<FRAME SRC="http://another.domain.com">
...
소유확인용 메타태그 정보가 html body 태그 내에 존재 시 검증에서 제외 처리합니다. html head 태그 내에 기입해 주세요.
# 소유확인용 메타태그가 body 태그내에 존재하므로 확인 불가
<html>
<head>
<title>예제</title>
</head>
<body>
<meta name="naver-site-verification" content="...."/>
</body>
</html>

url : https://searchadvisor.naver.com/guide/faq-branding
내용 : 
Q. 사이트 브랜드란 어떤 기능입니까?
브랜드는 URL에 더하여 해당 웹사이트 또는 웹페이지가 속한 사이트나 운영 주체에 대한 정보입니다.

image

클릭 시 해당 주체로 판단되는 웹사이트 또는 웹페이지가 속한 사이트로 연결됩니다.

이를 통해 URL만으로는 전달하기 어려울 수 있는 사이트에 대한 추가적인 정보를 제공합니다.

Q. 브랜드 영역은 어떻게 구성됩니까?
브랜드 영역은 네이버 검색 로봇이 자동으로 수집·분석하여 추출한 이름이 표시됩니다.

해당 정보는 자동으로 업데이트되며, 수집 상태나 사이트 구조 등에 따라 시시각각 변화할 수 있습니다.

다만, 자동으로 구성되는 영역인 만큼, 정확하지 않거나 부적절한 이름이 노출될 수 있습니다.

네이버 검색 로봇이 정보를 추출하기 어려운 경우, 사이트의 URL 일부가 브랜드로 노출될 수 있으며,
클릭 링크가 걸리지 않을 수도 있습니다.

Q. 브랜드 영역에 내가 원하는 정보를 노출 시킬 수 있습니까?
브랜드 영역은 로봇이 자동으로 수집 분석 추출하는 영역으로 자동으로 생성됩니다.

다만, 오류나 한계가 있을 수 있으므로, 잘못되었거나, 변화된 내용이 반영되지 않는 경우 등에는 고객센터를 통해 문의할 수 있습니다.
